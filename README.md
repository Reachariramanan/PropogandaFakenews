# Fake News & Propaganda Detection: modelling branch

This branch holds only the training and evaluation code. See [`MODELLING.md`](MODELLING.md) for what each stage does,
what it reads and writes, and how the pieces fit together.

The full codebase (verdict engine, annotation tool, Evidence Desk, docs) is on the `dev` branch, whose README
describes the whole project. Datasets, model checkpoints and credentials are not included in any branch.
